# Podstawowa Stacja Kontroli Pojazdów MOTO CENTRUM Milejowice/Radom

Praca na potrzeby przedmiotu **Aplikacje Internetowe**. Semantyczna, responsywna strona internetowa dla Podstawowej Stacji Kontroli Pojazdów w Milejowicach.

**Strona dostępna pod adresem:** https://countermsx.github.io/moto-centrum-skp/

**Zrealizowane wymogi i funkcjonalności:**
* **HTML5 & CSS3:** Semantyczna struktura, zmienne CSS, układy Flexbox i Grid.
* **RWD:** Pełna responsywność bez poziomych pasków przewijania (desktop, tablet, smartfon 375px+).
* **JavaScript:** 
  * Mobilne menu (hamburger menu).
  * Przełącznik motywu (Jasny/Ciemny) z zapisem w `localStorage`.
  * Interaktywny akordeon w sekcji FAQ.
  * Karuzela zdjęć (automatyczna i manualna).
  * Walidacja formularza kontaktowego (w czasie rzeczywistym i po opuszczeniu pola).
  * Przycisk powrotu na górę.

**Technologie:** HTML5, CSS3, JavaScript (ES6+).
